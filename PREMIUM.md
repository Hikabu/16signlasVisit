# Premium Quality System

This document defines execution quality.

Composition decides where objects live.

This document decides whether they deserve to exist.

The goal is simple:

Every screen should feel intentionally crafted.

Never generated.

Never templated.

Never assembled.

If something feels ordinary,
it is unfinished.

---

# Core Principle

Premium is not decoration.

Premium is precision.

Visitors should feel:

"This company cared about details."

before reading a single sentence.

Every pixel must increase trust.

Nothing exists to increase excitement.

---

# Screenshot Quality

Product screenshots are the most valuable visual asset.

Treat them like product photography.

Never use screenshots simply because they exist.

A screenshot earns attention only if it immediately communicates value.

Good screenshots have:

• one obvious focal point
• visible hierarchy
• readable content
• realistic density
• generous framing
• no unnecessary UI
• no fake numbers
• no lorem ipsum
• no decorative overlays

Crop aggressively.

Show only what supports the narrative.

Every screenshot should answer one question.

Never show an entire interface.

---

# Artifact Quality

Artifacts are evidence.

Evidence must feel authentic.

Every artifact should contain:

• real language
• realistic structure
• believable density
• timestamps
• metadata
• citations
• small imperfections

Perfect interfaces feel fake.

Real systems contain detail.

Detail creates trust.

Never invent complexity.

Reveal existing complexity.

---

# Typography

Typography communicates confidence.

Good typography removes effort.

Hierarchy must be obvious before reading.

Rules:

• fewer font sizes
• larger scale differences
• shorter line lengths
• generous whitespace
• consistent rhythm

Never decorate typography.

No gradient text.

No outlined text.

No oversized marketing headlines.

Large type communicates importance.

Whitespace communicates confidence.

---

# Layout Quality

Premium layouts feel inevitable.

Nothing feels placed.

Everything feels discovered.

Each viewport contains:

• one dominant object
• one supporting object
• one clear reading path

Remove anything competing for attention.

If two objects feel equally important,

both become weak.

---

# Visual Density

Premium interfaces balance silence with precision.

Large quiet areas.

Dense meaningful areas.

Never fill empty space.

Never reduce density inside evidence.

Artifacts become believable because they contain information.

Pages become premium because they contain restraint.

---

# Craftsmanship

Craftsmanship is visible through consistency.

Every spacing decision should feel intentional.

Every border should align.

Every radius should repeat.

Every margin should belong to a system.

Visitors never consciously notice craftsmanship.

They simply trust it.

Small inconsistencies destroy perceived quality.

---

# Interaction Quality

Interactions reveal understanding.

Never decorate interaction.

Every click should expose something valuable.

Every hover should clarify.

Every animation should explain.

Nothing should exist only because it looks interesting.

---

# Motion Quality

Motion reveals information.

Never attract attention.

Never entertain.

Never loop.

Motion begins only after user intent.

Timing:

200–400ms

Fast.

Precise.

Immediate.

The visitor should remember what became understandable.

Never remember the animation.

---

# Premium Objects

Objects deserve space according to value.

Highest priority:

• report
• evidence
• citations
• engineering record

Medium:

• headline
• CTA

Lowest:

• navigation
• controls
• labels

The interface supports the product.

The product supports the narrative.

---

# Premium Details

Trust lives inside details.

Examples:

• real timestamps
• repository names
• contributor names
• commit hashes
• review comments
• citation numbers
• realistic spacing
• believable metadata

Specificity always beats decoration.

---

# Stop Scroll Test

Within three seconds the visitor should notice:

1. A real artifact

2. Something impossible to fake

3. A clear claim

4. A reason to inspect

Curiosity should come from evidence.

Never from visual effects.

---

# Apple Test

Apple removes until only the essential remains.

Linear removes until interaction disappears.

Anthropic removes until only judgment remains.

16Signals removes until only evidence remains.

Do not imitate their visuals.

Imitate their discipline.

---

# Template Test

Before shipping remove the logo.

Ask:

Could this belong to another AI startup?

If yes,

remove more.

Then ask:

Could only a company built around engineering evidence create this screen?

If no,

rebuild it.

---

# Final Rule

Premium is the result of subtraction.

Every unnecessary pixel weakens trust.

Every meaningful detail strengthens it.

When uncertain,

remove.
