Act as a Staff Product Designer and Senior Frontend Engineer.

Redesign this landing page using the visual philosophy of Raycast, Linear, and Vercel.

The goal is NOT to copy their UI, but to achieve the same clarity, hierarchy, restraint, and premium feeling.

## Design Direction

This product is a Skill Verification Layer.

Core message:

"Proof once. Use everywhere."

We verify technical skills using 16 independent signals and convert that evidence into a portable skill profile that employers can trust.

The page should feel:

- premium
- technical
- trustworthy
- minimal
- enterprise-ready

Avoid startup clichés, giant gradients, flashy effects, glassmorphism overload, and oversized marketing sections.

---

## Background

Background color:

#010506

Create an extremely subtle engineering-grid system:

- thin 1px lines
- opacity between 3% and 6%
- large square cells
- almost invisible
- inspired by Raycast documentation visuals

Grid should remain fixed behind all content.

Optional:

- tiny dotted matrix pattern
- extremely low opacity

The background must never compete with content.

---

## Layout Philosophy

Use large breathing room.

Every section should feel like a technical blueprint.

Prefer:

- asymmetrical layouts
- large margins
- content blocks floating inside the grid

Avoid:

- giant centered text walls
- crowded cards
- excessive shadows

---

## Typography

Typography should do most of the work.

36-48px

Use strong contrast:

Primary text:
white

Secondary text:
#8B949E

Accent:
#009A93

---

## Color Usage

Primary accent:

#009A93

Use it sparingly.

Only for:

- active states
- progress indicators
- verification highlights
- important diagrams

Never fill large areas with accent color.

Most of the page should remain monochromatic.

---

## Information Hierarchy

Users should understand within 5 seconds:

1. What the product does
2. Why it matters
3. How it works
4. Why they should trust it

Everything else is secondary.
