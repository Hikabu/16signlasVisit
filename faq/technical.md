## How do I connect my GitHub account?

Open your Employer Dashboard and click **Connect GitHub**. You'll be taken through the GitHub OAuth flow — once authorized, your public repositories and contribution history are automatically synced.

## My GitHub connection failed. What should I do?

First, check that you approved the OAuth request in GitHub and that your account has public repositories. If the connection still fails, disconnect and reconnect your GitHub account from Settings. Still stuck? [Contact technical support](/contact?subject=technical) and include any error message you see.

## How long does an analysis take?

Most repository analyses complete within **5–10 minutes**. You'll get a notification when your evidence report is ready. Larger monorepos can take longer.

## Why is my repository showing as "not analyzed"?

A repository is only analyzed if it's **public** and we can access it through your connected GitHub account. If it was recently made public, try reconnecting GitHub. Private repositories are not analyzed for privacy reasons.
